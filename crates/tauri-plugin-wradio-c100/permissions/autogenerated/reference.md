## Default Permission

Default permissions for the wradio-c100 plugin: USB device discovery/open, scanning, tuning, service selection, live snapshot, and presets.

#### This default permission set includes the following:

- `allow-list-devices`
- `allow-open-device`
- `allow-start-scan`
- `allow-stop-scan`
- `allow-tune`
- `allow-start-service`
- `allow-stop-service`
- `allow-get-snapshot`
- `allow-list-presets`
- `allow-set-preset`
- `allow-clear-preset`
- `allow-list-stations`
- `allow-set-volume`
- `allow-mute`
